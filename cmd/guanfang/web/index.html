不选=不限。官方 IP 的落地地区随运营商线路变化，筛得越窄命中率越低、耗时越长。
▸ 指定 IP 段
留空=扫官方全部 IP 段（6500+ 个 /24）。填了就只扫你给的段：候选池小得多， 速度快很多，命中率也高 —— 前提是这些段在你的网络下确实好用。
支持 CIDR（104.16.0.0/13）、单个 IP、起止范围 （104.16.0.0-104.16.3.255）。一行一条或用逗号/空格分隔都行， # 和 // 开头按注释忽略。大段会自动切成 /24。
未指定，将使用官方 IP 段列表
▸ 高级选项
留空用 cloudflare.com。填你节点的域名可让结果更贴近实际；填错会导致全部测不通。
自动选择：先探测你的运营商，移动线路会换用对移动更友好的测速源。
填你自己域名下的一个大文件（100MB 以上），测出来的才是 「CF 边缘回源到你服务器」这条实际会用的链路的速度。必须带文件路径。
最快出结果；实际使用比优选结果慢很多时改 10 或 15 秒
候选 IP 从 Cloudflare 官方子网列表随机生成，大部分是不通的， 所以扫描时会反复换批次。填的带宽越高，需要的时间越长（最多 10 轮）。
